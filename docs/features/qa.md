# QA 质量保证：API 场景测试

## 当前阶段

仅实现前端交互原型，等待产品布局确认。入口为左侧活动栏功能列表末尾的「质量保证」（位于搜索文件之后），开发直达地址为 `http://127.0.0.1:5173/#qa`。没有新增后端服务、HTTP/MCP API、AI 生成能力、真实测试执行或持久化。

## 产品定位

AI 根据用户提供的前端代码，从产品角度推导用户可能的操作流，将每个操作映射到一组 API，再按顺序形成链式调用。目标是模拟用户行为、验证业务结果，不是生成单元测试。

## 布局与交互

- 左侧：复用文件管理器的 `FileTreeRow`、`TreeChevron` 及主题令牌，按系统模块 → 产品功能 → 场景组织；支持展开、收起、搜索和切换场景。侧栏沿用资源管理器的边缘收起/展开控件与拖拽调宽交互，宽度独立保存；支持双击恢复默认宽度和方向键调宽。
- 页面去除侧栏标题及计数说明、右侧面包屑栏；全局顶部搜索、CPU、主题按钮保持原有布局。
- 可读性：对齐工作台字号令牌，接口标题 14px、行为标题 13px、URL/请求体/行为说明 12px、辅助信息 11px；代码统一使用项目等宽字体。正文与辅助说明分别使用主文字色及次级文字色，选中组通过边框和背景高亮，其余组不再整体降低透明度；长 URL 保留完整悬停提示。
- 中间：按用户行为分组的 API 调用链，每个接口可以展开请求、响应、断言、变量。沿用 scenario-test 的请求诊断和上下文传递思路。
- 右侧：用户行为流程图。点击行为节点时，高亮并定位关联的一组接口；点击接口或分组时，反向选中行为节点。
- 提供联动视图、仅 API、仅流程三种视图。窄窗口将流程改为横向滚动，接口链放在下方；小屏目录可以收起。
- 「演示执行」通过前端计时器逐项展示模拟结果，可以停止、清除；所有状态与响应均为示例，不发送测试请求。
- 示例包含管理员添加用户、重复用户名被阻止、角色菜单授权。变量提取与跨请求使用展示 `userId` 的传递。

## 待确认与后续边界

本次没有实现场景编辑、流程拖拽/连线、真实环境配置、执行历史、AI 分析导入或变量求值。环境切换仅展示原型中的不同请求地址。

用户确认产品形态后再设计后端；未来的场景管理、执行、报告等业务能力必须由 `devflow-core` 统一实现，HTTP 与 MCP 共用服务、状态、权限及执行规则。

## 验证

按本阶段要求启动 Vite 开发服务并做浏览器交互检查，不运行构建或测试命令。浏览器已确认多余标题栏移除、顶部状态回到右侧、侧栏收起和展开；实测拖拽使目录宽度从 244px 变为 300px。2026-10-23 在开发页检查深浅主题，确认 URL 实际为 12px、接口标题 14px，所有接口组不透明度为 1。实际后端场景执行不属于当前阶段。
