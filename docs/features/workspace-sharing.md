# 工作区只读分享

## 使用

本机管理页面继续使用 `http://127.0.0.1:31080/`。工作区名称下拉菜单新增 **只读分享…**：确认目录范围、选择有效期，创建邀请，复制链接发给局域网成员。

默认访客监听 `0.0.0.0:31082`，链接形如 `http://192.168.1.100:31082/share/#<邀请凭证>`。弹窗尝试识别本机出口 IPv4，多个网卡/VPN 环境可能需要手动改成实际局域网地址。Windows 防火墙需要允许分享端口的入站访问，网络需允许成员之间互通；程序不自动修改防火墙。

链接持有者可查看工作区目录、UTF-8 文件、文件名/内容搜索、已发现服务的缓冲日志。没有保存、替换、启动/停止服务、Arthas 控制台、切换工作区或选择本机文件夹的能力。只读限制由后端独立路由和核心封闭操作枚举共同执行。

分享包含所列目录内允许读取的文件及服务日志，可能包含项目自身的配置内容。请仅发给可信成员；当前阶段提供局域网 HTTP 访问，不用于公网转发。HTTPS、实名访客、逐成员权限、实时协作编辑均未包含。

## 同一个工作台

分享设置表单复用公共表单防腐层 `BaseField / BaseSelect / BaseInput / BaseButton`，有效期、地址、邀请链接与全部操作按钮遵守相同主题、焦点和禁用规则；撤销使用公共危险按钮。外壳沿用工作区管理/启动配置的标题和底部操作栏布局，分享 CSS 只保留范围列表、字段间距和窄屏布局。字段标签与辅助说明通过唯一 ID 关联；有效期下拉在原生模态窗口内正确挂载。此轮已完成源码与差异检查，按约定未编译或运行测试。

分享入口与本机入口都挂载同一个 `App`，不再维护精简访客页面或访客专用布局。活动栏、目录树、目录宽度拖拽、搜索及筛选、文件标签页、Markdown/源码编辑器、服务卡片、运行指标和底部输出面板全部复用原有组件，主题切换也保持一致。

只读模式仅隐藏修改类操作：打开/切换/保存工作区、添加/移除目录、复制/删除磁盘文件、搜索替换、启动/停止与诊断控制。文件内容仍可选择、搜索、复制，目录路径右键复制继续保留；局域网 HTTP 下复制使用兼容回退。文件编辑器使用现有 readonly 属性，不自动保存。

统一 API 在分享模式下将已有读取请求适配到 `/api/shared/read`，后端继续调用相同核心服务。搜索支持现有的大小写、全字、正则、包含/排除条件；运行指标复用核心采样流程，但只采样邀请包含的项目。邀请失效时清除当前工作台内容，后续读取不再使用失效凭证。没有额外的确认流程或另一套导航。

## 文件自动同步与刷新恢复

访客正在查看的文件每 15 秒检查一次磁盘内容；页面隐藏暂停，切回前台或恢复联网时补查，补查最短间隔 5 秒。失败后按 30–60 秒退避；只检查活动文件，内容未变不更新编辑器，变更时原位更新并保留滚动/选择，不执行整页刷新。后台文件和目录树不跟随轮询，切换到尚未加载的标签时再读取。

访客当前标签的 sessionStorage 记录界面元数据：文件标签、活动文件、源码光标、目录展开及 Markdown 模式，硬刷新后恢复，并重新通过邀请授权读取内容；不缓存正文或未保存草稿，不将凭证写入界面元数据。邀请失效仍按原流程清空显示。该同步复用既有 HTTP 适配与共享核心读取规则，MCP 无新增业务接口。

## 生命周期与范围

- 默认邀请有效 1 小时，可选 15 分钟、4 小时、24 小时；核心范围为 5–1440 分钟，最多保留 16 个有效邀请。
- 邀请只绑定创建时的工作区配置与已授权目录，文件内容是实时磁盘数据。分享者之后切换、关闭工作区或添加其他目录，不会扩大或切换已有邀请的范围。
- 邀请管理列表显示工作区、目录和到期时间，不返回凭证。凭证只在创建时返回一次；关闭弹窗后如未保存链接，需要重新创建邀请。
- 点击撤销立即阻止后续读取，并在慢读取结束时再检查撤销/过期状态。已下载、复制或截图的内容无法收回。访客页面定期检查邀请，失效时清除当前显示并提示联系分享者。
- 邀请只存于内存，重启后台全部失效。撤销旧邀请后可继续创建新邀请。
- 邀请使用独立随机凭证，不能用本机管理令牌访问访客读取接口，也不能用邀请凭证访问本机管理接口。

## 网络与安全边界

本机管理监听和既有 Host/Origin 检查保持不变。访客端口只注册：

| 路径 | 用途 |
| --- | --- |
| `/share/` | 访客页面 |
| `/assets/*`、`/vendor/*` | 与本机相同的构建资源及 Markdown 编辑器资源 |
| `POST /api/shared/read` | 持邀请 Bearer 凭证执行封闭的读取操作 |

访客端口没有 `/api/session`、文件写入、工作区管理、运行控制或 `/mcp` 路由，其他路径返回 404。请求来源和 Host 限于回环/私有 IPv4、实际分享端口及同源请求；不授予 CORS。附带 no-store、no-referrer、禁止框架嵌入、nosniff 。只读请求体最多 16 KiB，HTTP 最多同时处理 8 个读取请求；复用原核心读取、搜索的路径、大小、数量与超时限制。

链接凭证在 URL fragment 中，不放入查询参数或服务器请求路径。访客页面读取后移除 fragment，只在当前标签页 sessionStorage 保留凭证供刷新使用。API 使用独立 Bearer 凭证；访客从不获取本机管理令牌。

分享的 WorkspaceService 只包含创建时的实际目录授权，不能继承所有本机允许根目录或系统选择器授权。HTTP/MCP 均调用同一核心创建、撤销、过期和读取规则；适配层不重复业务权限判断。

## 管理接口与 MCP

| 本机 HTTP | MCP | 用途 |
| --- | --- | --- |
| `GET /api/workspace/shares` | `workspace_share_list` | 有效邀请及访客监听信息 |
| `POST /api/workspace/shares` | `workspace_share_create` | expectedRevision、lifetimeMinutes 创建邀请 |
| `POST /api/workspace/shares/revoke` | `workspace_share_revoke` | 按 id 撤销邀请 |
| 独立访客端口 `POST /api/shared/read` | 本机 `workspace_share_read` | 通过邀请权限读取指定工作区 |

MCP 仍是本机管理端入口，需要本机管理令牌；`workspace_share_read` 供本机 AI 在邀请权限范围内读取/验证，局域网访客没有开放的 MCP 入口。访客不能调用分享管理工具。

读取请求使用 `type`：`workspace`、`children`（path）、`file`（path）、`search`（query，可选 mode/caseSensitive/wholeWord/regex/includeGlob/excludeGlob）、`runtime`（分享工作区的运行指标）、`metrics`（DevFlow 自身指标）、`output`（projectPath，可选 script/after/runId）。核心拒绝未知操作和多余字段，不接受任意命令或写入内容。

## 配置

`DEVFLOW_SHARE_BIND` 默认 `0.0.0.0:31082`，可设为具体私有 IPv4 地址，例如 `192.168.1.100:31082`；设为 `off` 禁用。只接受回环、私有或通配 IPv4 绑定；监听失败不阻止本机管理服务启动，分享弹窗显示失败原因。双击启动器继承环境变量，`.env.example` 不会自动加载。
